# Documentation Athalia

Documentation de la plateforme Athalia (automatisation DevOps). Le site est proposé en **thème sombre** par défaut lorsque votre système est en mode sombre.

## Accès rapide

| Public | Document |
|--------|----------|
| **Utilisateurs** | [Guides utilisateur](USER_GUIDES/INDEX.md) — installation, usage, FAQ, dépannage |
| **Développeurs** | [Index développeur](DEVELOPER/INDEX.md) — architecture, API, bonnes pratiques |
| **API** | [Référence API](API/INDEX.md) — modules, orchestrateur, sécurité |

## Structure

- **USER_GUIDES/** — installation, quick start, usage, déploiement, robotique
- **API/** — documentation des modules et serveur API
- **ARCHITECTURE/** — structure du projet, organisation
- **DEVELOPER/** — guides dev, maintenance, plans, rapports
- **REPORTS/** — rapports d’audit et bilans ([voir README](REPORTS/README.md))
- **GETTING_STARTED/** — raccourcis vers l’installation

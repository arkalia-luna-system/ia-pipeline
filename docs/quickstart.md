# Guide de démarrage rapide

## Installation

```bash
pip install athalia-ai
```

## Configuration

1. Créez un fichier de configuration `athalia_config.yaml`
2. Configurez vos paramètres d'environnement
3. Lancez Athalia

```bash
athalia --help
```

## Premier projet

```bash
athalia create-project mon-projet
```

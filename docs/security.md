# Sécurité

## Audit de sécurité

Athalia intègre plusieurs outils d'audit:

- Bandit pour l'analyse statique
- Safety pour les vulnérabilités des dépendances
- Pip-audit pour l'audit des packages

## Bonnes pratiques

- Validation des entrées
- Chiffrement des données sensibles
- Gestion sécurisée des secrets
